关于本政策

本应用由 Evander 提供。我们重视你输入的内容及抽牌记录。本政策适用于隐象手机应用，说明应用如何在设备上处理这些信息。

处理哪些信息及用途

你可以选择输入问题和两个比较选项，也可以不填写。完成抽牌后，应用在本机保存抽牌日期、牌阵、输入的问题及选项、抽中的牌和方向，用于展示结果与历史记录；应用还会保存逆位开关设置。未使用联网解读时，问题不会被分析。配置 DeepSeek 后，你可以主动点击解读，将本次问题、选项、牌阵、抽中的牌与方向及对应牌义发送给 DeepSeek，以生成结合问题的解释。生成的解读会随本条记录保存在本机；应用不会自动发送全部历史。

存储与删除

记录保存在设备的应用本地存储中。历史最多保留最近100次，较早记录会被新记录替换；每日一牌还单独保存，用于当天重复查看同一结果，并在下次生成每日牌时替换。你可以在“占卜记录”中逐条删除记录及随记录保存的解读；删除历史记录不会重置单独保存的今日牌。DeepSeek API Key 保存在手机的应用安全资产存储中，只在设备解锁时读取，不写入普通记录或安装包；可在设置中删除。你也可以通过设备系统清除应用数据或卸载应用，实际删除、备份与迁移行为以设备系统设置为准。删除本机记录不能撤回已经发送给第三方的请求。

联网、权限与第三方

抽牌、本地牌义和记录不需要联网，也不要求注册或登录。可选的 DeepSeek 解读通过官方 HTTPS 接口 api.deepseek.com 发送本次问题及牌阵，使用你配置的 API Key 计费；设置页面说明发送范围。应用为此声明网络访问权限，未接入第三方统计、广告或登录SDK。应用不会把密钥、问题或记录上传给本应用提供者。DeepSeek 对请求的处理适用其服务条款和隐私政策（https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html）；启用前请阅读并避免输入不必要的敏感信息。操作系统、应用市场及自行启用的备份或迁移服务按各自政策处理信息。

安全与未成年人

应用数据使用设备的应用本地存储；请注意保护设备和系统备份，避免他人未经允许访问。如果你是未成年人，请在监护人指导下阅读本政策并使用本应用。
